# Weekly Academy Timetable

A simple, drag-and-drop enabled weekly timetable for managing academy schedules.

## Features
- **Visual Schedule**: View your week at a glance with a clean grid layout.
- **Drag & Drop**: Move classes between days or times easily.
- **Resize**: Drag the bottom handle of any class to adjust its duration.
- **Pastel Aesthetic**: Randomly assigned pastel colors for a pleasant look.
- **Local Storage**: Your schedule is saved automatically in your browser.

## How to Use
1. Open `index.html` in any modern web browser.
2. Click the **+** button at the bottom right to add a new class.
3. Enter the details (Name, Time, Duration) and save.
4. Drag notes to reschedule or resize them to change duration.
5. Double-click a note to delete it.

## Deployment
This project is built with pure HTML, CSS, and JS. You can deploy it directly to **GitHub Pages** by uploading these files to a repository and enabling Pages in settings.
